## Помощник Eltex {version}

Программа для коммутаторов MES23xx, MES24xx и маршрутизаторов ESR (MES2308, MES2324, MES2411X, ESR-12V, ESR-15R, ESR-200).

**Что внутри:** справочник команд с поиском по-русски, шаблоны конфигураций, проверка конфигурации под модель, сканирование сети (ping, SSH, Telnet, HTTP/HTTPS, SNMP, MAC), работа по SSH, Telnet и через консольный порт, бэкапы, безопасная заливка конфигурации (на ESR: commit → проверка доступа → confirm) и графический интерфейс в браузере.

### Какой файл скачать

| Файл | Для чего |
|---|---|
| `EltexHelper-{version}-win7-x64.zip` | Windows 7 / 8 / 10 / 11, 64 бита. Ничего устанавливать не нужно: распаковать и запустить `EltexHelper.bat`. |
| `EltexHelper-{version}-win7-x86.zip` | То же для 32-битной Windows. |
| `eltex_assistant-{version}-py3-none-any.whl` | Установка в имеющийся Python 3.8+ (Linux, Astra Linux SE 1.8, Windows): `pip install eltex_assistant-{version}-py3-none-any.whl` |
| `SHA256SUMS.txt` | Контрольные суммы файлов. |

На Windows 7 нужны Service Pack 1, обновление KB2999226 и браузер Chrome 109 или Firefox 115 ESR.

### Важно

- Справочник собран по общему синтаксису серий и не сверен построчно с документацией каждой прошивки. У каждой записи есть пометка достоверности; хуже всего проверена серия MES24xx.
- Программа проверена тестами и в эмуляторе Windows, но ещё не запускалась на настоящем оборудовании и на настоящей Windows 7. Первый запуск лучше сделать на некритичном устройстве.
