# Помощник Eltex

Программа командной строки для работы с коммутаторами и маршрутизаторами Eltex:

* **справочник команд** с поиском по задаче на русском («настроить транк», «проброс порта»);
* **сравнение синтаксиса** между сериями (MES23xx, MES24xx, ESR): одна задача, три варианта команд;
* **шаблоны конфигураций** (базовая настройка коммутатора, абонентские порты, ESR для офиса);
* **проверка конфигурации** перед заливкой: ловит синтаксис чужой серии (маска vs префикс, `commit` на MES, порты `0/N` vs `1/0/N`, слабые пароли);
* **автоматизация по SSH, telnet и через консольный порт**: show-команды на много устройств сразу, бэкапы с diff, безопасное применение конфигурации;
* **сканирование сети**: ping, порты SSH/Telnet/HTTP/HTTPS, SNMP, MAC-адреса, определение моделей Eltex и запись найденного в список устройств;
* **графический интерфейс** в браузере: `eltex gui` (на Windows можно запускать двойным щелчком по `EltexHelper.bat`).

Сейчас поддержаны: MES2308, MES2324 (семейство `mes23xx`), MES2411X, MES2408, MES2428 (`mes24xx`), ESR-12V, ESR-15R, ESR-200 (`esr`).

## Установка

Нужен Python 3.8+ (Windows, Linux, macOS).

```
pip install ./eltex-assistant
eltex -h
```

Без установки: `python -m eltex_assistant -h` из папки проекта.

## Графический интерфейс

```
eltex gui
```

Откроется страница в браузере с вкладками: справочник, шаблоны, проверка, сканирование сети, устройства. Программа работает только на вашем компьютере (адрес 127.0.0.1) и защищена одноразовым ключом в ссылке, поэтому открывать её нужно по ссылке, которую печатает `eltex gui`. Пароли устройств вводятся в окне и никуда не записываются. Список устройств хранится в `inventory.yaml` в папке, откуда запущена программа.

## Сканирование сети

```
eltex scan 192.168.1.0/24
eltex scan 10.0.0.10-50 -c public -c mycommunity --save-inventory inventory.yaml
```

Для каждого адреса проверяются ping, TCP-порты 22, 23, 80, 443 с чтением баннеров, SNMP v2c и v1 (sysDescr, sysName, sysObjectID) и MAC из ARP-таблицы компьютера. Модель Eltex определяется по ответам SNMP, заголовку веб-интерфейса и баннерам. Соседей по LLDP показывает `eltex ssh neighbors`. Сканируйте только свои сети.

## Консольный порт и telnet

```
eltex console                      # список COM-портов
eltex console COM3                 # интерактивный терминал, 115200 8N1, выход Ctrl+]
eltex ssh run  --serial COM3 -m MES2324 -c "show version"
eltex ssh push sw.cfg --serial COM3 -m MES2324
eltex ssh run  --host 10.0.0.11 --telnet -m MES2308 -c "show version"   # старые прошивки без SSH
```

В инвентаре: `transport: serial` + `serial_port: COM3` или `transport: telnet`. В Linux порт выглядит как `/dev/ttyUSB0`, пользователь должен входить в группу `dialout`.

## Как попасть с одного коммутатора на соседний

```
eltex show remote-connect -m MES2324
```

Коротко: `show lldp neighbors gigabitethernet 1/0/N` покажет адрес управления соседа, затем `ping` и `telnet <IP>` (или `ssh <IP>`, если клиент есть в вашей версии ПО). Связь будет, только если VLAN управления разрешён в транке на обоих концах.

## Переносной пакет для Windows 7

Windows 7 поддерживает Python не новее 3.8, а свежие библиотеки шифрования на ней не работают, поэтому для неё собирается отдельный пакет: Python 3.8.10 и проверенные версии библиотек внутри, без установки и без интернета.

```
python packaging/build_win7.py        # dist/EltexHelper-<версия>-win7-x64.zip и -x86.zip
```

На Windows 7: распаковать и запустить `EltexHelper.bat` (графический интерфейс) или `eltex.bat` (командная строка). Нужны Service Pack 1, обновление KB2999226 и браузер Chrome 109 или Firefox 115 ESR.

## Примеры

```
eltex models                                   # модели и особенности семейств
eltex search настроить транк -m MES2324        # найти команды под задачу
eltex search nat интернет -m ESR-12V
eltex show save-config                         # как сохранить конфиг на всех сериях
eltex list -m esr                              # всё, что есть в справочнике по ESR
eltex ask -m MES2308                           # интерактивный режим вопрос-ответ

eltex template list
eltex template render access-ports -m MES2324 -p vlan=10 -p ports=1-20 \
      -p uplink="tengigabitethernet 1/0/1" -p uplink_vlans=10,100 -o sw.cfg
eltex check sw.cfg -m MES2324                  # проверка синтаксиса под модель

eltex ssh run -i examples/inventory.yaml -c "show version" -c "show interfaces status"
eltex ssh backup -i examples/inventory.yaml -o backups
eltex ssh push sw.cfg -i examples/inventory.yaml -d sw-floor1 --dry-run
eltex ssh push sw.cfg --host 10.0.0.11 -m MES2324 -u netadmin
```

Пароли не храните в инвентаре: задайте `ELTEX_PASSWORD` (или `ELTEX_PASSWORD_<ИМЯ>`), иначе программа спросит.

## Как работает `ssh push` (и кнопка «Проверить и отправить»)

1. Файл проверяется под семейство устройства; при ошибках отправка не начинается.
2. Показывается, что будет отправлено, и запрашивается подтверждение («да»). `--dry-run` только показывает.
3. Команды отправляются; при ответе устройства `% Unrecognized command` и т.п. отправка останавливается.
4. Дальше по семейству:
   * **MES23xx**: `copy running-config startup-config` (+ ответ `Y`);
   * **MES24xx**: `write startup-config`;
   * **ESR**: `commit` → новый SSH-сеанс для проверки, что доступ не потерян → `confirm`. Если зайти заново не удалось, `confirm` не выполняется и ESR сам откатывает изменения по таймеру. При ошибке команды делается `rollback`.

На коммутаторах MES автоматического отката нет: команды до ошибки уже применены в running-config (но не сохранены — перезагрузка вернёт прежнее состояние).

## Пометки достоверности

Каждая запись справочника имеет `confidence`:

* `high` — стандартный синтаксис серии;
* `medium` — помечается «проверьте «?» на устройстве»;
* `low` — черновик, синтаксис не подтверждён.

Справочник собран по общеизвестному синтаксису серий, а не сверен построчно с документацией каждой версии ПО. Особенно это касается MES24xx. Уточнения вносятся прямо в YAML.

## Как расширять

* Новая модель: строка в `eltex_assistant/kb/models.yaml` с нужным `family`.
* Новая серия со своим CLI: семейство в `models.yaml` + файл `kb/commands/<семейство>.yaml` + правила в `checker.py`.
* Новая команда: запись в `kb/commands/<семейство>.yaml` (формат описан в начале `mes23xx.yaml`). Одинаковый `id` в разных семействах = одна задача, тогда `eltex show <id>` покажет сравнение.
* Новый шаблон: файл в `kb/templates/` (Jinja2, тела по семействам).
